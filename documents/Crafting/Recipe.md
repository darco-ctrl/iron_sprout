# Recipe
Recipe data tells crafting what item to make how much durability, hunger it takes, what are ingredients used 

Recipe Data has 6 properties

| Property             | Description                                  |
| -------------------- | -------------------------------------------- |
| Name                 | Name of recipe                               |
| Ingredient Data      | [[Ingredient]]                               |
| Hunger Depletion     | Hunger depletion per crafting                |
| Tool Required        | [[Tool Data]] required to craft the [[Item]] |
| Result Item          | product [[Item]]                             |
| Result Item Quantity | product quantity                             |
